◈ Sprite Animator

64 × 64

Import

Import sheet slices a grid of frames. "Auto-detect" finds the most even grid that fits the image. "Insert image" pastes/drops a cut-out drawing into the current frame.

Align

Align All re-centers every frame on its alpha-weighted centroid, then fits its bounding box so the sprite stays rock-steady across the loop. Use nudge for fine manual offset. Turn on the reference grid to hand-align drawings against a fixed guide.

Resize frame

Hand-drawn assets are rarely the same size. Scale a frame up/down (nearest-neighbor, crisp pixels) or force every frame to a target size before aligning/exporting.

Tags (animation ranges)

Frame ranges become TexturePacker/ASEprite frameTags. Godot/Tiled read them by name (idle, walk, attack…).
Solarus expects rows = directions (right, up, left, down), columns = frames per direction. "Solarus view" lays the sheet out that way so you can verify; "Export Solarus" writes the PNG + .dat sprite.
